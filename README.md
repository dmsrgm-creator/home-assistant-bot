# Ассистент Вася 🤖

Домашний ассистент с интеграцией с Home Assistant, работающий через Telegram.

## Функционал
- [x] Telegram бот
- [x] Интеграция с Home Assistant
- [x] Команды: /time, /date, /datetime
- [ ] Управление умным домом
- [ ] Поиск в интернете
- [ ] Голосовое управление

## Команды
- `/time` - текущее время
- `/date` - текущая дата
- `/datetime` - дата и время
- `/clear` - очистить историю диалога
- `/stats` - статистика
- `/unload` - выгрузить модель из памяти

## Установка
1. Клонировать репозиторий
2. Создать .env из .env.example
3. Установить зависимости
4. Запустить бота

## Стэк
- Python 3.11+
- python-telegram-bot
- llama-cpp-python
- Home Assistant API
